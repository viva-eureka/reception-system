# 入退館記録「メモ」列について

管理画面ダッシュボードの「入退館記録」に表示される **「メモ」列** の仕様に関する説明です。

## 結論

**現状、「メモ」列にはどのレコードでも何も記載されません（常に「—」表示）。**
受付画面にメモの入力欄はなく、システム上どこからも書き込まれない、**将来用に確保された空の列**です。

## 詳細（コード上の挙動）

- 入退館記録テーブルの「メモ」列は、行の描画で**常に固定の「—」を表示**します。レコードの値を参照せず、データを差し込む処理がありません。
  - 該当コード：`index.html`
    ```jsx
    {c.key === "memo" && <span className="text-slate-400 text-xs italic">—</span>}
    ```
- Supabase（`reception_visits`）から入退館記録を読み込む際のデータ整形にも **`memo` 項目自体が存在しません**（保持しているのは 日時・氏名・会社・区分・担当・入退館状況 など）。
- したがって受付画面に**メモ入力欄が無い**のも当然で、書き込む経路がどこにもありません。
- **CSV出力**でもメモ列は常に空になります。

## 参考：似た項目「要件」との違い

- 別画面の **「来訪者ログ」（`/visitor-log.html`）** には「**要件**」列があり、こちらは実データ（来訪の目的 = `visit_purpose`）を表示します。招待作成時などに要件が入っていれば表示されます。
- 一方、管理画面の「入退館記録」は要件を表示せず、空の「メモ」列を置いている状態です。

## 今後の選択肢（未確定・要相談）

|----|------|----------|
| **A案** | 紛らわしい「メモ」列を**削除** | 小 |

| **C案** | 受付時に**メモを入力できる欄を追加**し、記録・表示できるようにする | 中〜大 |
